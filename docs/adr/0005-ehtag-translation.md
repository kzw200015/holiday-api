# 标签译名取自 EhTagTranslation，逐条存库、手动同步

标签与命名空间的中文名用 EhTagTranslation 社区维护的数据库（`release` 分支上的 `db.text.json`），本站只显示、不维护。译名在后端套上，接口直接回带译名的标签：整库 4 MB，交给前端的话手机每次都要下载，国内设备直连 GitHub 也不稳。

译名逐条存库（命名空间、原文、译名），读的时候按条查、用 `lru-cache` 缓存（没有译名的标签也缓存，免得长尾标签每次都查库），而不是存一份整表快照或整表读进内存：逐条的数据在库里看得见、查得到，方便管理。同步只能在设置页手动触发，不设定时任务，启动时也不拉：上游一天改二十多次，跟不跟得上都无所谓，什么时候换成新版本由人决定；缺了译名只是显示原文，不像节假日安排那样会答错，所以首次部署时库是空的也照常启动。每次同步在一个事务里整表替换，与上游保持一致，同步后清空缓存。

## Consequences

- 数据按 CC BY-NC-SA 3.0 中国大陆协议使用：要署名（设置页），**不得商用**，衍生数据要以相同协议分享。本站若要商用，得换掉这个数据源。
- 同步是一次长请求（下载加上写入四万多行），同一时刻的多次同步合并成一次；任何已登录的本站账号都能触发，这依赖「注册默认关闭、账号都是自己人」，开放注册前要先收紧。
