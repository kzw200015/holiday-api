# 鉴权自己写，不用 Spring Security

本站账号的鉴权只有三件事：用户名和密码换一张无状态令牌、请求头带令牌认人、少数接口放行。为这点事引入 Spring Security 的过滤器链和配置 DSL，读代码时要先弄懂一整套框架约定，出了问题也不直观。所以鉴权由我们自己写：拦截器默认要求登录，`@Public` 标出放行的接口，`@CurrentUser` 把当前账号注入控制器参数（参数可空即未登录不报 401）；令牌是用 JDK `Mac` 手写的 HS256 JWT；密码哈希只借 BouncyCastle 做 argon2 运算，PHC 串的解析与比对自己写。

## Consequences

- 默认要登录、放行靠显式标注：漏标的代价是多一次 401，而不是把接口裸露出去。公开接口的清单由测试锁住，新增公开接口必须同时改那份清单。
- 令牌无状态，服务端不存已签发的令牌，没法提前作废，也没有 logout 接口；要全端下线得另加令牌版本号并在每次校验时查库。
- 图片接口由 `<img>` 直接发起、带不了请求头，不走令牌，靠地址签名认人，同样标 `@Public`。
