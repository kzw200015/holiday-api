# 用 Go 重写服务

服务原来是 Rust（axum + sqlx），现在用 Go 重写：Echo 处理 HTTP，viper 读配置，sqlc 生成查库代码，goose 管迁移，wire 生成组装代码。Rust 的实现与工具链全部删掉。这是重写而不是移植：旧实现只用来弄清对外行为；已有的库原地接管，数据不丢。

几处取舍：

- **入口在 `cmd/myapi`，组装在 `internal/app`，部件的构造交给 wire**：`main` 只管信号与退出码；wire 按构造函数的参数生成接线代码（`wire_gen.go`，提交进仓库），加部件时不必手排构造顺序。wire 没有启停钩子，只管构造：迁移算作「把连接池造好」，在 `database.NewPool` 里做；配置也由 wire 提供：生产的 injector 用 `config.Load` 读环境变量，测试的 injector 换成测试给的配置，其余构造函数两者共用一个 set，测的都是真实的组装。启动刷新、后台任务、监听这些运行期的步骤显式写在 `internal/app` 的 `app.run` 里，监听与优雅关停交给 Echo 的 `StartConfig`；只有两样东西要启停，不为它们另起 Start/Stop 的抽象。各包只导出构造函数，要配置的直接收 `config.Config`，不 import wire、不声明 `ProviderSet`，构造函数统一列在 `internal/app/wire.go` 的 `parts` 里；代价是这些包都依赖了 `config`。wire 上游已不再活跃，但生成的只是普通 Go 代码，哪天不用了，把 `wire_gen.go` 留下当手写代码即可。
- **Echo v5**：新项目没有迁移包袱，v4 往后只修 bug。
- **pgx/v5 + pgxpool，sqlc 生成 pgx 的代码**：按年替换是在一个事务里先删、再用 `:copyfrom`（PostgreSQL 的 COPY）批量插入。goose 要 `*sql.DB`，经 `stdlib.OpenDBFromPool` 借同一个池子。sqlc 与 wire 都用 `go.mod` 的 `tool` 指令固定版本，生成的代码提交进仓库；代价是 sqlc 的依赖也记进了 `go.mod`（只在 `go tool` 时编译，不进服务的二进制）。
- **goose 当库用，迁移 SQL 经 `embed` 编进二进制，启动时执行**：多个实例同时启动时经 advisory lock 排队。第一个迁移用 `CREATE TABLE IF NOT EXISTS`，Rust 版建的表形状相同，原样接管；sqlx 的迁移登记 `_sqlx_migrations` 删掉。只支持 Rust 版迁移过的库与空库。
- **失败体改成 `{code, message}`**：`code` 是 UPPER_SNAKE 的业务错误码，HTTP 状态码照旧表达类别。Echo 自己拒绝的请求（入参解析不了、路径不存在、方法不对等）`message` 用 Echo 的英文原话；5xx 回「服务器出错了」，原文只进日志。原来的 `{statusCode, message, error}` 取消，调用方的错误处理要同步改。
- **两条节假日接口只保证路径与成功时的响应体不变**：`date` 交给 Echo 按 `YYYY-MM-DD` 解析，不再接受 `20260104`、`2026-01-04T10:30` 这类 ISO 8601 的宽松写法；留空与省略一样表示北京时间的今天。
- **日期在代码里是 `time.Time`（UTC 零点）**：Go 没有只表示日期的类型，不为它另起类型或引库；「只有日期」由入参解析、sqlc 的类型映射与响应体的格式化三处把关。北京时间是固定的 UTC+8（中国自 1991 年起不实行夏令时），用不着时区库。
- **环境变量沿用 Rust 版的名字**：`DATABASE_URL`、`PORT`、`OUTBOUND_TIMEOUT`、`OUTBOUND_USER_AGENT`，新增 `HOLIDAY_SOURCE_URL`；日志级别从 `RUST_LOG` 改成 `LOG_LEVEL`。viper 只读环境变量，不读配置文件，也不读 `.env`；校验手写，写错了进程拒绝启动。
- **探针与启动顺序照 Rust 版**：迁移与启动时的节假日刷新都做完才开始监听，`/api/health/live` 只看进程自己，`/api/health/ready` 还要数据库连得上。
- **出网用 `net/http`**：不跟随重定向，连接超时 10 秒；`OUTBOUND_TIMEOUT` 从「多久没收到一个字节」改成「整个请求最多多久」，数据源一年一个几 KB 的文件，用不着区分。代理照 Go 的惯例读 `HTTPS_PROXY`。
- **定时刷新手写**：只有每天北京时间 4:30 一个时刻，用计时器等到下一个 4:30，不引 cron 库。
- **日志用 `log/slog` 的文本格式，不记请求日志**。
- **格式与检查交给 golangci-lint v2**，断言用 testify 的 `require`。

## Consequences

- 部署要跟着改：`RUST_LOG` 换成 `LOG_LEVEL`；调用方要按新的失败体改错误处理。
- 第一次在 Rust 版迁移过的库上启动时删掉 `_sqlx_migrations`；想回到 Rust 版，就得手工把登记补回去。
